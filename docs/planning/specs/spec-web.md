# Ethplane spec extract for the build swarms · from the private PRD, 2026-09-08 19:04 · private to host A, never commit this file

## 3.9 Web (Next.js 15 app router, `output: 'export'`, TypeScript, Tailwind, shadcn/ui, Aceternity; data via `lib/api.ts` fetch to `/api/*` with `cache: 'no-store'`; polling 8 s on node and swarm pages)
Pages and their components (component = file in `components/`; every component takes typed props from `lib/types.ts`, has loading/empty/error markup, and uses only `--wp-*` tokens):
- `/` **Map** (`StrawmapGrid`): three layer bands, fork columns G,H,I,J,K,L, longer term, north stars; track rows; node tiles from `/api/nodes` positioned by `layer, track, fork` per `research/strawmap-nodes.json`; tile = label, tag chip (EIP/SFI/CFI), SPEC chip (outline) when criterion_type is reviewed checklist, state ring (open violet / leased amber / verified green / locked grey); throughline arrows from `throughlines_to`. Filters: layer, fork. Click → `/node/[id]`. Empty state: all 65 tiles locked with "not yet funded"; the map must read as the strawmap with zero leases (designer QA section F).
- `/node/[id]` **Node page**, zone order from the designer's card and PLAN §12.3: zone 1 four columns: `CriterionCard` (type, definition, noise floor, threshold, non-regression fields), `LeaseCard` (active leases with countdowns; claim control: "Claim" / "Claim alongside · N groups hold this" with start-from picker (node head or a lineage frontier) / disabled with assignee + time on pre-assigned lanes), `CoordinationCard` (current task's `mode` and `reason` from the latest HANDOFF line of the holding host; "no lease, no mode yet" when empty), `GovernanceCard` (EF tier, EIP links, fork, arc). Zone 2: `LeaseTimeline` (SVG; every claim, heartbeat, forfeit, expiry, submission, verdict in order; broken time axis with break glyphs and the compression stated), `SubmissionsTable` (hash, lineage, parents, verdict, metric, spread), `CheckpointTree` (DAG of submissions by parents, heads marked). Zone 3: `AttributionTable` (rows by kind and operator, linking `/operator/[addr]` is out of scope; show totals inline), `BoardTail` (last 20 board lines from the holding hosts), `FreshnessBlock` (last indexed block and time; per-event links to `https://sepolia.etherscan.io/tx/<tx>` and to `/api/nodes/:id`), `JoinBox` (Privy login → guest name; the five CLI commands from `docs/JOIN.md` with the user's guest name filled in; a HINT form posting `POST /api/board` as kind HINT with the guest's identity; a review-verdict form posting kind REVIEW with a checklist).
- `/swarm/[host]` **Swarm view**: `RolePanes` (orchestrator, builder, critic: status, current HANDOFF and criterion, last BUILT/REVIEW), `BoardTail` (200 lines, mode and reason columns shown), `MembersList` (lineage identity, model, joined guests). No transcripts.
- `/deck` **Deck**: 12 full-viewport sections built from shadcn cards and Aceternity transitions; keyboard ← → and print CSS (`@page` landscape) so `Cmd+P` yields the PDF. Slide order: 1 the question (§0); 2 the strawmap as the map; 3 one node, the criterion; 4 the lifecycle in three phases (§20.1-20.3); 5 the baton; 6 identity and attribution; 7 ENS as the contribution tree; 8 Privy funding flow; 9 what a judge can verify; 10 roadmap coverage (65 / 4 / 29 / 32 from `/api/nodes`); 11 the business use case; 12 how it was built (local-model swarms on two hosts, board line count) and attribution to AI per ATTRIBUTION.md.
- `/docs` **Docs**: sidebar + MDX render of `docs/SPEC.md`, `docs/JOIN.md`, `docs/CRITERION-pq-leanxmss.md`, `docs/DEPLOY.md`, `research/*.md` (tables scroll inside their container), `research/strawmap-nodes.json` and `coverage.json` rendered as sortable tables.
- Wallet: Privy React provider only (guests); no wallet connect for admins (CLI only).
- State: `useSWR`-style polling hook `usePoll(url, 8000)`; master-detail selections re-synced on each poll (`setSelected(prev => fresh.find(...) ?? prev)`).



## 3.2 Design system (no decisions during the build)
- `design/DESIGN.md` is generated before any component with `npx @google/design.md` (the `design-md` skill) from: `design/tokens.json` (copied from the designer package `design/tokens.json` in the run dir: strawmap palette sampled from the PNG, state ring colours, type scale) and `design/references/` (the strawmap PNG, an EIP page screenshot, a Linear issue view, an Etherscan log view, the designer's variant C snapshot). Lint it; commit it.
- Components: shadcn/ui (`npx shadcn@latest init`, then `add button card badge table tabs dialog sheet tooltip scroll-area separator`), Aceternity UI blocks for the deck hero and section transitions. The only hand-written visual component is `components/LeaseTimeline.tsx` (SVG, broken time axis with visible break glyphs, per the designer's card).
- Light theme only. System sans; monospace only for hashes, keys and event rows. Every number has a source on hover.
- Tokens as CSS variables in `design/tokens.css` imported once in `app/globals.css`; Tailwind reads them through `tailwind.config.ts` `theme.extend.colors` mapping `--wp-*` variables. No other colours.
